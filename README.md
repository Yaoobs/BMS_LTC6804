# BMS_LTC6804

9 串锂电池从机 BMS。STM32F103C8T6（72 MHz，64 KB Flash，20 KB SRAM）经 SPI 读取 LTC6804 的单体电压，自己采集电流和温度，开关充放电 MOS，估算 SOC，并在过压、欠压、过流时关断。上位机用 115200 文本命令切换充电、放电和待机。

控制算法用 Simulink 和 Embedded Coder 生成，不在 C 里手写状态迁移和保护判断。充放电状态机、过充过放、安时积分、被动均衡在 `Model/`，板上编译的是仓库根目录里对应的 `*_ert_rtw/`。手写代码只做集成：调度、LTC6804 命令和 PEC、电流窗口、串口、掉电保存。改门槛或状态迁移时重新生成模型，采样和 SPI 不用跟着改。仿真里看过的逻辑，和板上跑的是同一份代码。

硬件是 9 节接在 12 个通道上，第 6、11、12 节不接。总电压按 9 节平均。未接通道的 0 mV 在取最小前换成一个很高的数，不会把欠压锁死。均衡模型已经生成；板上没有均衡硬件，两处写寄存器保持注释。

## 两个调度

先做成裸机协作式时间片，再改成 FreeRTOS。当前工程跑的是 RTOS。裸机的 `Os_Task()` 已从 `os.c` 去掉，步骤留在 `docs/时间片调度.md`。

| | 裸机时间片 | FreeRTOS（当前） |
| --- | --- | --- |
| 时基 | SysTick 每 1 ms 只置标志，主循环按 5 ms 里的槽位执行 | SysTick 交给内核，HAL 时基改到 TIM4 |
| 电流 | 1 ms 采一点，100 ms 槽位上平均 | 最高优先级。1 ms 采一点，满 100 ms 墙钟再平均入队 |
| 电压 | 100 ms 发 ADCV，满 4 ms 后在主循环开头一次读完四组 | 100 ms 发 ADCV 就放锁，空等 4 ms，四组各读一次 |
| 保护与 MOS | 读完电压的同一圈做完 SOC、保护、状态机、MOS | 数据处理线程做 SOC 和保护；控制线程做命令、状态机和 MOS |
| 上报 | 1 s 槽位采温度、翻转 LED、发文本 | 报告线程 1 s 做同样的事，并按条件喂狗 |
| 看门狗 | 每次进入主循环就喂，超时大约 8 s | 电流、电压、控制都活着，且五条业务线程栈余量都不少于 128 字节，才喂 |

裸机的顺序是固定的。电压读取排在电流采样前面，四组一次读完大约 1.4 ms。这段时间里 1 ms 标志只有一位，到期的采样丢掉，不会插进 SCK。任务不能抢占：读电压或擦 Flash 时，后面的电流、保护和上报都要等这次调用返回。

RTOS 把转换等待让出来。ADCV 发出后立刻放开 SPI 锁，芯片大约 2.3 ms 转完，线程等 4 ms，这 4 ms 里电流线程照常采样。SPI 还在进行时，以及四组读完后的 20 ms 内，电流点不入窗，躲开时钟沿对采样脚的牵拉；1 ms 的醒来节拍不挪。零点是 1361 mV。±0.5 mV 当成 0，1 mV 对应 50。高于零点为放电（负），低于零点为充电（正）。过流看这一窗平均是否越出 ±2000，也就是零点以外 40 mV。

## 算法

SOC 用开路电压查表和安时积分衔接。查表做整数线性插值，单位是 0.01%，串口显示成 `78.00%`。积分步长 0.1 s，和 100 ms 电压帧对齐。电量在中间段信任积分；高于 80% 或低于 30%，并且和查表相差超过 10% 时，改用查表值并清掉积分量，修正会留下来。待机命令把 SOC 和总电压写入片内最后一页，下次上电作为积分起点。

保护带恢复门槛：过压 4200 / 4100 mV，欠压 2800 / 3100 mV。过流和这两个标志合成故障。状态机在控制线程里跑，按待机、充电、放电、故障改两只 MOS。上电后 MOS 保持关闭，直到离开待机。

## 串口

`C` 充电，`D` 放电，`S` 待机并把 SOC、总电压写入 Flash。中断收满一行再交给控制线程。上报走发送队列，每秒发出 SOC、电流、总电压和两只 MOS，不占着线程空等。
