**9-Cell Lithium Battery Slave BMS Based on STM32F103C8T6 + LTC6804** | Independent Development (Open Source: github.com/Yaoobs/BMS_LTC6804) | 2026.08 – 2026.10

- **System Architecture:** SPI reads cell voltages from LTC6804; independent current and temperature acquisition; controls charge/discharge MOS; estimates SOC; cuts off output on over-voltage/under-voltage/over-current faults. Implements both bare-metal time-slice and FreeRTOS five-thread versions.
- **Real-Time Scheduling Refactoring:** Addressed second-level protection response caused by blocking delays in the main loop by migrating to a FreeRTOS five-thread architecture, with the current sampling thread at the highest priority and a depth-1 queue carrying only the latest frame; **protection response compressed to under 100 ms**, with immediate command response.
- **Sampling Anti-Interference Design:** Addressed ~0.8 mV quantization jitter per ADC conversion causing zero-point noise in current readings by adopting 1 ms sampling window + 100 ms moving average before conversion, with dead zone applied to the averaged value; **no-load current stabilizes within the dead zone while small currents remain proportionally preserved**.
- **MBD Algorithm Generation:** State machine/protection/Ampere-hour integration/passive balancing modeled in Simulink, C code generated by Embedded Coder and compiled directly on-board, achieving **identical code in simulation and on-board, algorithm-driver decoupling**; threshold changes only require model regeneration, no secondary driver integration.
- **SOC Estimation and Safety Shutdown:** Ampere-hour integration fused with OCV lookup (Coulombic efficiency 0.99, integration trusted in the mid-range, voltage correction at both ends, automatic switch to lookup with integration reset when deviation exceeds limit); over-voltage/under-voltage with hysteresis (4200/4100 mV, 2800/3100 mV), over-current based on 100 ms average current; faults shut down both MOS; forced reset within 8 s on abnormality.
- **Reliability and Power-Loss Protection:** SOC and total voltage written to Flash during standby; watchdog fed by current, voltage, control heartbeat and five-thread stack margin; communication interrupt receives lines, queues to control thread, status reported once per second.
