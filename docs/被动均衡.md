# 被动均衡

待机时按单体毫伏选出偏高的节，把放电开关写进 LTC6804。充电、放电和故障时关掉这些开关。判断在 `balance_ert_rtw/balance.c`（模型 1.29）。Keil 编译的是这一份。写寄存器在 `Core/PeripheralSrc/LTC6804.c`，调用点在 `os.c` 的 `Voltage_Poll()`。

## 现状

### 什么时候执行

`Task_100ms()` 发出 ADCV 并记下时刻。`Voltage_Poll()` 在每次 `Os_Task()` 开头被调用。差值还不到 4 ms，或者还没有待读的转换，函数直接返回。这一圈不跑保护、状态机、MOS 和均衡。

满 4 ms 后的顺序是：

1. `LTC6804_rdcv()` 读完四组，`Get_TotalVoltage()` 换成毫伏，`SOC_Estimator()`。
2. `protect_step()`，再把 `CriticalFault` 写成 `OV_FLAG || UV_FLAG`。
3. `state_machine_step()`，`JudgeBMSState()` 按新的 `BMS_State` 改两只 MOS。
4. 仍是待机：`balance_step()`，`send_balance_commend()`，`balance_on_flag = 1`。
5. 不是待机，且 `balance_on_flag == 1`：`exit_balance_commend()`。

`balance_on_flag` 上电为 0，置 1 之后没有再清 0。第一次待机采样之后，每次充电、放电或故障的电压结果都会再写一次关闭命令。

串口在两次转换完成之间只改 `StateRequest`。MOS 和均衡要等下一次电压读完才跟着变，间隔大约 100 ms。

充电和放电对切时，状态机一步只回到待机。这一拍关掉两路 MOS，并按待机把均衡写进芯片。下一拍采样才进入另一个运行状态，再写关闭命令。

`balance_initialize()` 是空的，工程里没有调用。`cell_balance[12]` 上电为 0。

### 选哪一节

输入是 `cell_voltage[12]`，单位 mV，下标 0 是第 1 节。`balance_step()` 先在 12 路里取最大。平均只累加大于 0 mV 的节，再除以这些节的个数。12 路都是 0 时平均按 0。

门槛是：

```text
0.4 × 最大 + 0.6 × 平均 + Offset
```

`Offset` 当前是 16。生成代码里的 0.4 来自 `52429 × 7.62939453e-6`。某一节严格大于这个门槛时，`cell_balance[i] = 1`，否则为 0。

9 节电压相同、另外 3 节为 0 时，门槛等于这一电压加 16 mV，没有任何一节被置 1。未接的第 6、11、12 节保持 0 mV 时不进平均。只剩 9 节参与时，一节要比其余节高出 30 mV 以上才会被置 1。正好高出 30 mV 时等于门槛，不打开。

等于 0 mV 的已接节同样被排除，也不会被选中。非 0 的读数都进入平均和最大。原始码 `0xFFFF` 换成约 6553 mV 后，会成为最大并被标成需要均衡。

### 写进芯片

`send_balance_commend()` 调用 `config_balance_registers(cell_balance)`，再 `LTC6804_wrcfg()`。配置 6 字节是：

| 字节 | 值 | 含义 |
| --- | --- | --- |
| 0 | `0xFC` | GPIO 保持 1，REFON 打开，ADCOPT 为 0 |
| 1～3 | `0x00` | 片内欠压、过压比较门槛为 0。保护不用这组比较结果 |
| 4 | DCC1～DCC8 | `cell_balance[0]`～`[7]`，置 1 的下标对应位写 1 |
| 5 低 4 位 | DCC9～DCC12 | `cell_balance[8]`～`[11]` |
| 5 高 4 位 | `0x1` | DCTO。`cfgr5_val \|= 0x10` |

DCTO 为 0 时放电开关关闭，DCC 置 1 也不导通。`0x1` 是 0.5 分钟。每次 `LTC6804_wrcfg()` 都会按这个值重新计时。待机里大约每 100 ms 写一次，开关在待机期间保持当前这组 DCC。DCC 全 0 时开关仍然断开，只是超时位不是 0。

`exit_balance_commend()` 仍写 `0xFC`，第 4、5 字节为 0。DCC 和 DCTO 都是 0，放电开关关掉。

上电 `LTC6804_initialize()` 把 6 字节写成 `0xFC` 和 5 个 0，此时不放电。ADCV 命令 `0x0360` 的 DCP 为 0：转换的大约 2.3 ms 里芯片暂停放电，转换结束后按配置寄存器恢复。

下标和开关的对应关系：

| `cell_balance` 下标 | 节 | 位 |
| --- | --- | --- |
| 0～7 | 第 1～8 节 | CFGR4 的 DCC1～DCC8，位 0 起 |
| 8～11 | 第 9～12 节 | CFGR5 的 DCC9～DCC12，位 0 起 |

第 6、11、12 节未接，对应下标 5、10、11。它们停在 0 mV 时 DCC 保持 0。
